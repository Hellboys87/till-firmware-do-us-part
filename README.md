One robot wedding vow in a single sentence, under 200 characters: a promise to love through forced updates and late-night reboots, to save the last of its battery for its partner's bad days, and to restart softer instead of shutting down mid-argument. The program writes that one line to `entry.txt`.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/output node main.ts
```

It writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (default `/output`).
